# Health-Ease Landing Page

A modern, responsive landing page for a healthcare booking platform that allows users to skip clinic queues and manage appointments digitally.

## 🚀 Features

* Appointment booking section
* Clear "What do we offer" process
* Call-to-action for conversions
* Responsive layout (mobile-friendly)

## 🛠️ Built With

* HTML5
* CSS3 (Flexbox & Grid)
* JavaScript

## 📸 Preview

- Live Site URL - https://ndilisa.github.io/health-ease-landing-page/

## 📂 Project Structure

* `index.html` – Main structure
* `style.css` – Custom styling
* `main.js` – Main function interactivity

This project was built to practice semantic HTML, layout structuring, and responsive design principles.
